# Launchly Landing Page

## Project Title

Landing Page using HTML5 and CSS3

## Objective

Build a visually polished static landing page for a product,
service, or brand.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Web Design
- No JavaScript

## Features

- Sticky navigation bar
- Four navigation links
- Hero section
- Headline and subheadline
- Call-to-action buttons
- Features section
- About section
- Testimonial section
- Contact section
- Footer
- Social media links
- Responsive mobile layout
- Consistent colour palette
- Clean typography
- No element overlap
